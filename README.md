# Ben Athem website

Static author website for **benathem.com**, designed for GitHub Pages.

## Publishing

Upload the contents of this folder to the root of the existing GitHub Pages repository. Keep `CNAME` in place so the custom domain remains connected.

## Services already connected

- Reader List: Kit embed on `index.html`
- Contact form and ARC applications: Formspree
- Custom domain: `benathem.com` through `CNAME`

## Main pages

- `index.html` — homepage and complete book catalogue
- Individual book pages — descriptions and retailer/Goodreads links
- `arc-team.html` — ARC information and application form
- `extras.html` — free stories and downloads
- `about.html` and `contact.html` — standalone information pages

Large original artwork is preserved. Optimised website copies are stored in `images/web/` and used on the busiest pages for faster loading.
